# Guia de Erros Comuns

## Macro bloqueada

Configure a pasta como local confiável no Excel ou desbloqueie o arquivo `.xlsm` se ele for próprio e confiável.

## Script PowerShell não executa

Verifique política corporativa, antivírus, caminho do script e permissões de leitura.

## Arquivo inacessível

Pode estar aberto, sem sincronização local no OneDrive, sem permissão ou com caminho longo.

## Extração falhou

Confirme se o aplicativo Microsoft 365 correspondente está instalado e se o arquivo não está protegido por senha.

## PDF digitalizado sem texto

A primeira versão deixa estrutura preparada para OCR futuro, mas não exige OCR.
