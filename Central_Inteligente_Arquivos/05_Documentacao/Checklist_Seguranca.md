# Checklist de Segurança

- [ ] A pasta analisada é de teste ou foi autorizada.
- [ ] A usuária entende que a ferramenta não exclui, move ou renomeia originais.
- [ ] A pasta de saída foi conferida.
- [ ] Macros foram habilitadas apenas em local confiável.
- [ ] Scripts PowerShell vieram de fonte confiável.
- [ ] Desbloqueio será usado apenas em arquivos próprios e confiáveis.
- [ ] Nenhuma senha será quebrada.
- [ ] Nenhuma permissão corporativa será burlada.
- [ ] Logs serão revisados após a execução.
