# Como criar o arquivo XLSM

1. Abra o Excel Desktop.
2. Crie uma nova pasta de trabalho em branco.
3. Salve como `Central_Inteligente_Arquivos.xlsm` dentro da pasta `01_Excel`.
4. Pressione `ALT + F11` para abrir o Editor VBA.
5. Use `Arquivo > Importar arquivo...` e importe todos os módulos `.bas` da pasta `02_VBA`.
6. Volte ao Excel e execute a macro `InicializarCentral`.
7. Revise a aba `CONFIGURACOES`.
8. Use a aba `PAINEL` para operar a solução.

## Local confiável

Para evitar bloqueios indevidos, salve o projeto em uma pasta confiável do Excel ou configure a pasta como local confiável em `Arquivo > Opções > Central de Confiabilidade`.
